# AB Testing: From SQL to Decision

## TL;DR
Одно-два предложения: что за задача, какой был результат.
(Например: "Тестировал гипотетическую новую версию онбординга —
показал полный пайплайн от сырых событийных логов до бизнес-рекомендации.")

## Задача
Развёрнутое описание бизнес-контекста: что тестируем, зачем,
какая метрика успеха, какая guardrail-метрика.

## Пайплайн
1. SQL: агрегация сырых событий в метрики на пользователя
2. Проверка SRM
3. Power analysis
4. Статистический тест (+ обоснование выбора метода)
5. Проверка гетерогенности по сегментам
6. Итоговая рекомендация

## Ключевые решения (это отдельно выделить!)
- Почему Welch, а не обычный t-тест
- Почему добавил Mann-Whitney
- Почему важна SRM-проверка
